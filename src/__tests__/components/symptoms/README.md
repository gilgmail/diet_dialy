## 🐛 常見測試問題與解決

### 問題1: 測試超時
**原因**: API模擬未正確設置
**解決**: 確保所有API調用都有對應的mock

### 問題2: 組件未渲染
**原因**: 缺少必要props
**解決**: 檢查defaultProps配置

### 問題3: E2E測試失敗
**原因**: 選擇器變更或載入時間
**解決**: 使用更穩定的選擇器，增加等待時間

## 📝 維護指南

### 新增測試
1. 確定測試類型 (Unit/API/E2E)
2. 遵循現有測試結構
3. 添加描述性測試名稱
4. 確保測試獨立性

### 更新測試
1. 組件變更時同步更新測試
2. 保持測試與實現同步
3. 定期檢查測試覆蓋率

### 測試審查清單
- [ ] 測試名稱清晰描述意圖
- [ ] 測試獨立且可重複
- [ ] 模擬數據真實
- [ ] 斷言具體且有意義
- [ ] 錯誤情況有涵蓋

## 🎓 測試最佳實踐

1. **AAA模式**: Arrange → Act → Assert
2. **單一職責**: 每個測試只驗證一件事
3. **描述性命名**: `should do X when Y`
4. **獨立測試**: 不依賴其他測試的執行順序
5. **清理資源**: 使用beforeEach/afterEach清理
