```bash
cd mobile/react-native-starter-kit/DietDailyMobile

# 安裝依賴（如需要）
npm install

# 啟動 Metro bundler
npm start

# 在另一個終端啟動 iOS app
npm run ios
```

## 🍽️ Test Suite 1: 飲食記錄 (Food Diary)

### 測試目標
驗證用戶可以完整記錄每日飲食，包括新增、檢視、編輯、刪除功能。

---

### Test 1.1: 新增飲食記錄（基本流程）

**前置條件**:
- App 已啟動並登入
- 位於 Food Diary 畫面

**測試步驟**:
1. 點擊「新增飲食記錄」按鈕
2. 選擇用餐時間（早餐/午餐/晚餐/點心）

4. 輸入份量：「1 碗」
5. （可選）新增備註：「家裡煮的」
6. 點擊「儲存」
