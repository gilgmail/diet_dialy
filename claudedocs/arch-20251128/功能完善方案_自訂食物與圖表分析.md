#### 資料處理

**熱力圖資料準備**:
```typescript
// 從 daily_symptom_entries 查詢
const heatmapData = await supabase
  .from('daily_symptom_entries')
  .select('recorded_date, abdominal_pain, diarrhea, ...')
  .eq('user_id', userId)
  .gte('recorded_date', startDate)
  .lte('recorded_date', endDate)

// 轉換為熱力圖格式
const formattedData = heatmapData.map(entry => ({
  date: entry.recorded_date,
  severity: calculateSeverity(entry),
  // ...
}))
```

**食物頻率資料準備**:
```typescript
// 從 food_entries_new 查詢
const foodFrequency = await supabase
  .from('food_entries_new')
  .select('food_name, category, entry_date')
  .eq('user_id', userId)
  .gte('entry_date', startDate)

// 聚合統計
const frequencyMap = foodFrequency.reduce((acc, entry) => {
  const key = entry.food_name
  acc[key] = (acc[key] || 0) + 1
  return acc
}, {})
```
