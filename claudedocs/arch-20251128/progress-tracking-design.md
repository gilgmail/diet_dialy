# 進步追蹤設計方案

## 核心概念

「進步」功能旨在讓用戶看到自己的健康改善趨勢，提供正向回饋和持續動力。

## 設計原則

1. **正面鼓勵**：強調改善，而非問題
2. **視覺化**：使用圖表、箭頭、顏色直觀展示
3. **多維度**：從不同角度展示進步（記錄習慣、症狀改善、資料完整度）
4. **個人化**：根據用戶實際情況顯示相關進步指標

## 進步指標設計

### 1. 記錄習慣進步 📈
- **連續記錄天數**：本週 vs 上週
- **記錄頻率**：本週記錄天數 vs 上週
- **資料覆蓋率**：本週覆蓋率 vs 上週覆蓋率
- **視覺化**：
  - 上升箭頭 ↑ + 百分比變化
  - 進度條對比（本週 vs 上週）
  - 文字：「本週比上週多記錄了 X 天！」

### 2. 症狀改善進步 🎯
- **症狀頻率**：本週症狀天數 vs 上週
- **症狀嚴重程度**：平均嚴重程度變化
- **健康天數**：本週健康天數 vs 上週
- **視覺化**：
  - 下降箭頭 ↓（症狀減少是好事）
  - 健康天數增加
  - 文字：「本週症狀天數減少了 X 天！」

### 3. 資料完整度進步 📊
- **各類別覆蓋率**：症狀、飲食、用藥、睡眠、運動
- **完整記錄天數**：本週完整記錄天數 vs 上週
- **視覺化**：
  - 各類別進度條對比
  - 星級評分提升
  - 文字：「資料完整度提升了 X%！」

### 4. 健康狀態進步 💚
- **健康天數比例**：本週健康天數 / 總天數
- **大便次數穩定性**：是否維持在 0-2 次正常範圍
- **視覺化**：
  - 健康天數統計
  - 趨勢圖表
  - 文字：「本週有 X 天健康狀態良好！」

### 視覺元素

1. **箭頭圖示**：
   - ↑ 綠色：進步
   - ↓ 紅色：退步（但症狀減少用綠色）
   - → 灰色：持平

2. **百分比變化**：
   - 正數：綠色 `+15%`
   - 負數：紅色 `-5%`
   - 零：灰色 `0%`

3. **進度條對比**：
   - 上週：淺色、較短
   - 本週：深色、較長
   - 並排顯示，直觀對比

4. **卡片設計**：
   - 圓角、陰影
   - 漸層背景（進步時用綠色系）
   - 圖示 + 數據 + 趨勢

## 資料來源

### 需要查詢的資料

1. **本週資料**（過去 7 天）：
   - 記錄天數
   - 症狀記錄
   - 資料覆蓋率
   - 健康天數

2. **上週資料**（再往前 7 天）：
   - 同上

3. **計算進步**：
   - 本週值 - 上週值 = 變化量
   - (本週值 - 上週值) / 上週值 * 100 = 變化百分比

## 實作步驟

### Phase 1: 基礎進步卡片
1. 建立 `ProgressCard` 組件
2. 顯示本週 vs 上週的關鍵指標
3. 視覺化進步趨勢

### Phase 2: 詳細進步分析
1. 各類別詳細對比
2. 趨勢圖表
3. 進步里程碑

### Phase 3: 個人化建議
1. 根據進步情況提供建議
2. 設定下週目標
3. 慶祝進步里程碑

## 鼓勵訊息設計

### 進步時
- 「太棒了！本週比上週多記錄了 3 天！🔥」
- 「健康狀態改善明顯，繼續保持！💚」
- 「資料完整度提升了 15%，AI 分析會更準確！✨」

### 持平時
- 「保持穩定記錄，這很棒！👍」
- 「繼續維持這個好習慣！💪」

### 退步時（友善提醒）
- 「沒關係，明天再繼續記錄！💪」
- 「小提醒：記得記錄今天的資料哦 📝」

## 整合位置

1. **洞察頁面 - 進度分頁**：
   - 放在 `StreakCard` 和 `DataCoverageCard` 之間
   - 作為激勵元素

2. **今日任務分頁**：
   - 顯示「本週進步」小卡片
   - 鼓勵完成任務

3. **報告頁面**：
   - 在週報中顯示進步趨勢
   - 作為長期追蹤的一部分
