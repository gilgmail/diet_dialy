# Phase A 資料覆蓋率改善指南

## 當前狀況

**使用者**: kogil0231@gmail.com  
**症狀記錄覆蓋率**: 26.7%  
**目標覆蓋率**: 60% 以上  
**狀態**: ⚠️ 部分（需要改善）

## 改善策略

### 階段 1：快速補記（最近 7 天）

**目標**: 補記最近一週的缺漏記錄

**步驟**:
1. 登入應用程式
2. 進入症狀記錄頁面
3. 選擇缺漏的日期（從最近開始）
4. 填寫基本資訊：
   - 整體健康評分（必填）
   - 至少一個核心症狀（腹痛/腹瀉/血便/脹氣）
   - 如果記得，補充心情、精力、睡眠品質

**預期效果**: 覆蓋率可提升至約 40-45%

### 階段 2：持續記錄（建立習慣）

**目標**: 每天記錄，連續 7 天

**建議時間**:
- **晚上 8-9 點**: 回顧當天症狀
- **睡前**: 補充睡眠和運動資料
- **早上**: 如果前一天忘記，可以補記

**技巧**:
- 設定手機提醒
- 將記錄納入日常例行公事
- 即使只記得基本資訊也要記錄

### 階段 3：補記歷史資料（可選）

**目標**: 補記過去 14-30 天的資料

**注意事項**:
- 不記得詳細資訊也沒關係
- 有基本記錄就能提高覆蓋率
- 優先補記最近兩週的資料

## 快速補記模板

即使只記得基本資訊，也可以使用以下模板：

```json
{
  "overall_health": 3,  // 1-5 分（必填）
  "abdominal_pain": 2,  // 0-5 分（可選，但建議至少填一個）
  "diarrhea": 0,        // 0-5 分
  "bloody_stool": 0,    // 0-5 分
  "bloating": 1,        // 0-5 分
  "mood_score": 3,      // 1-5 分（可選）
  "energy_level": 3,    // 1-5 分（可選）
  "sleep_quality": 3    // 1-5 分（可選）
}
```

## 注意事項

1. **資料品質 vs 覆蓋率**
   - 優先提高覆蓋率（有記錄比沒記錄好）
   - 即使資料不完整，也能提高覆蓋率
   - 後續可以再補充詳細資訊

2. **不要過度補記**
   - 如果完全不記得，不要猜測
   - 只補記確實記得的資訊
   - 重點是建立持續記錄的習慣

3. **設定提醒**
   - 使用手機提醒功能
   - 將記錄時間固定
   - 連續記錄 7 天後習慣會自然形成
