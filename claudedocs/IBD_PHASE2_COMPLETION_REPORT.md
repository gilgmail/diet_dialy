## 🚀 核心功能特點

### AI 營養師評分系統
```typescript
// 專業 IBD 營養評分
POST /api/ai/nutrition-score
{
  "foodName": "白米飯",
  "category": "主食",
  "nutrition": { "calories": 130, "protein": 2.7, "carbohydrates": 28, "fat": 0.3 }
}

// 回應
{
  "success": true,
  "score": { "value": 3, "level": "推薦", "emoji": "✅" },
  "analysis": {
    "reasoning": ["屬於IBD患者友善食物"],
    "recommendations": "推薦食用，對IBD患者相對安全且有營養益處",
    "confidence": 0.8
  },
  "method": "fallback"
}
```
