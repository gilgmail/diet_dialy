# Diet Daily - 五階段漸進式開發計劃

**版本**: 2.0
**最後更新**: 2025-01-12
**策略**: 漸進式價值交付 (Incremental Value Delivery)

---

## 🎯 整體策略

### 核心理念
**先建立習慣，後加入智能**

1. **資料優先**: 讓用戶先養成記錄習慣，累積足夠資料
2. **漸進增強**: 每階段增加新功能，避免初期過載
3. **價值遞增**: 每階段都為用戶創造明確的新價值
4. **快速驗證**: 第一階段快速上線，驗證市場需求

### 用戶成長路徑
```
階段 1: 記錄習慣建立 → 手動 AI 分析
階段 2: 遊戲化激勵 → 提高留存率
階段 3: 深度追蹤 → 完整健康圖像
階段 4: 即時建議 → 主動健康管理
階段 5: AI 自動化 → 智能健康顧問
```

class RecommendationEngine {
  // 計算食物風險
  calculateFoodRisk(
    food: Food,
    profile: PersonalHealthProfile
  ): RiskScore {
    // 1. 通用風險評分
    const baseRisk = food.commonTriggers[profile.condition]

    // 2. 個人歷史風險
    const personalRisk = this.getPersonalRisk(food, profile)

    // 3. 當前狀態調整
    const statusAdjustment = this.adjustForCurrentStatus(profile)

    return weighted(baseRisk, personalRisk, statusAdjustment)
  }

  // 生成替代建議
  suggestAlternatives(
    food: Food,
    profile: PersonalHealthProfile
  ): Food[] {
    // 尋找類似但風險較低的食物
    return this.findSimilarSaferFoods(food, profile)
  }
}

### 技術實現

#### Claude AI 整合
```typescript
class AIWeeklyReportGenerator {
  async generateReport(
    userId: string,
    startDate: Date,
    endDate: Date
  ): Promise<WeeklyReport> {
    // 1. 收集資料
    const data = await this.collectData(userId, startDate, endDate)

    // 2. 建立 AI prompt
    const prompt = this.buildPrompt(data)

    // 3. 呼叫 Claude API
    const analysis = await this.callClaudeAPI({
      model: 'claude-sonnet-4',
      prompt: prompt,
      maxTokens: 4096
    })

    // 4. 結構化輸出
    return this.parseAIResponse(analysis)
  }

  buildPrompt(data: UserHealthData): string {
    return `
你是一位專業的消化系統健康顧問。請分析以下患者資料，生成週報。

患者資訊：
- 病症：${data.condition}
- 資料期間：${data.period}

飲食記錄：
${JSON.stringify(data.meals, null, 2)}

症狀記錄：
${JSON.stringify(data.symptoms, null, 2)}

請提供：
1. 本週健康概覽
2. 飲食分析（營養、高頻食物）
3. 症狀模式分析
4. 可能的觸發食物識別（基於時間關聯）
5. 個性化飲食建議
6. 趨勢對比（vs 上週）
7. 下週目標建議

請用繁體中文，專業但易懂的語言。
    `
  }
}
```
