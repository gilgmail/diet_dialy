# Debug 模式使用指南

## 功能總覽

Debug 模式讓你可以：
1. 📥 **載入預設提示詞** - 查看系統目前使用的 AI 提示詞
2. ✏️ **修改提示詞** - 根據需求調整分析重點
3. 💾 **儲存自訂提示詞** - 保存你的修改
4. 🗑️ **清除恢復預設** - 回到系統預設設定

## 如何啟用 Debug 模式

### 步驟 1: 進入 Settings
1. 開啟 DietDaily App
2. 點擊 Dashboard 右上角的 **⚙️ 設定**按鈕
3. 滾動到最下方「開發者選項」區塊

### 步驟 2: 開啟 Debug 模式
1. 打開「Debug 模式」開關
2. 會出現「自訂 AI 提示詞」編輯區域

## 使用方式

### 🔍 查看預設提示詞

點擊「**載入預設**」按鈕：
- 會顯示目前系統使用的完整提示詞
- 彈出視窗會告訴你：
  - 變體名稱（例如：綜合分析營養師）
  - 變體描述
  - 提示詞已載入到編輯器中

**範例**：
```
已載入預設提示詞

變體：綜合分析營養師

平衡評估營養亮點、潛在風險與腸道修復策略的全面分析。

您可以在此基礎上修改。
```

### ✏️ 修改提示詞

載入預設後，你可以：

1. **增加特定關注點**
   ```
   在原提示詞最後加入：

   ## 額外關注重點
   - 特別留意高 FODMAP 食物（洋蔥、大蒜、豆類）
   - 評估乳製品（牛奶、起司、優格）的影響
   - 分析辛辣食物與症狀的關聯
   ```

2. **調整分析風格**
   ```
   修改提示詞前段：

   ## 分析風格調整
   - 更簡潔的摘要（減少到 2 句話）
   - 只列出高風險食物（忽略中低風險）
   - 強調實際可執行的建議
   ```

3. **加入個人化指示**
   ```
   ## 個人化設定
   - 我對麩質敏感，特別關注含麩質食物
   - 我正在嘗試低組織胺飲食
   - 請提供替代食物建議
   ```

### 💾 儲存提示詞

兩種儲存方式：

1. **自動儲存** - 離開編輯框時自動儲存
2. **手動儲存** - 點擊「**儲存提示詞**」按鈕
   - 會顯示「已儲存」確認訊息
   - 同步到 Supabase 雲端

### 🗑️ 清除提示詞

點擊「**清除**」按鈕：
- 彈出確認對話框
- 確認後清空自訂提示詞
- 恢復使用系統預設提示詞

## 實際應用範例

### 範例 1: 聚焦 FODMAP 食物

```
你是一位擁有 20 年臨床經驗的資深 IBD 營養師...

## 額外分析重點（自訂）
請特別關注以下高 FODMAP 食物：
- 洋蔥、大蒜（果聚糖）
- 蘋果、西瓜（果糖）
- 牛奶、優格（乳糖）
- 豆類、扁豆（半乳寡糖）
- 菇類、花椰菜（甘露醇）

對於這些食物，請：
1. 標註 FODMAP 類型
2. 評估與症狀的時間關聯
3. 提供低 FODMAP 替代方案
```

### 範例 2: 簡化輸出格式

```
（保留原提示詞前半部分）

## 輸出格式調整
- summary: 限制在 2 句話內
- foods_to_monitor: 只列出 high 風險（忽略 moderate 和 watch）
- supportive_foods: 最多 5 項
- gut_health_recommendations: 3 個可執行的具體建議
```

### 範例 3: 特定症狀追蹤

```
（保留原提示詞）

## 症狀追蹤重點
請特別關注以下症狀模式：
- 腹痛 - 評估與餐點的時間關係（餐後 0-2 小時 vs 6-12 小時）
- 腹瀉 - 識別可能的誘發食物組合
- 脹氣 - 分析纖維類型和發酵食品的影響

對於症狀分析，請：
1. 明確標示症狀發生時間
2. 推測可能的誘發食物（基於時間邏輯）
3. 建議測試方法（排除法、輪替飲食）
```

## 提示詞調整技巧

### ✅ 好的調整範例

1. **具體的指示**
   ```
   請在 foods_to_monitor 中加入「FODMAP 類型」欄位
   ```

2. **明確的優先順序**
   ```
   優先分析：1) 乳製品 2) 麩質 3) 豆類
   ```

3. **可量化的要求**
   ```
   summary 限制在 100 字內
   foods_to_monitor 最多列出 5 項
   ```

### ❌ 避免的調整

1. **過於模糊**
   ```
   幫我分析得更好 ❌
   ```

2. **矛盾的指示**
   ```
   要詳細分析，但保持簡短 ❌
   ```

3. **不切實際的要求**
   ```
   預測下週會發生什麼症狀 ❌
   ```

## 測試與比較

### 測試流程

1. **建立基準**
   - 使用預設提示詞執行一次分析
   - 記錄結果

2. **修改提示詞**
   - 載入預設提示詞
   - 加入你的調整
   - 儲存

3. **執行新分析**
   - 在 Dashboard → 💡 洞察 → 點擊「一週 AI 分析」
   - 等待分析完成

4. **比較結果**
   - Dashboard → 📝 報告 → 查看最新報告
   - 比較分析結果的差異

### 評估標準

好的提示詞調整應該：
- ✅ 更貼近你的實際需求
- ✅ 提供更具體的建議
- ✅ 更容易執行
- ✅ 幫助你找到真正的誘發因子

## 常見問題

### Q: 自訂提示詞會影響所有分析嗎？
A: 是的，儲存後的所有新分析都會使用自訂提示詞。

### Q: 可以恢復到預設嗎？
A: 可以，點擊「清除」按鈕即可恢復預設。

### Q: 提示詞會同步到其他裝置嗎？
A: 會，儲存在 Supabase，所有登入的裝置都會使用相同的自訂提示詞。

### Q: 修改提示詞有字數限制嗎？
A: 技術上沒有限制，但建議保持在合理範圍（< 5000 字）以確保 AI 處理效率。

### Q: 可以分享我的提示詞給其他人嗎？
A: 目前需要手動複製貼上。未來可能加入提示詞分享功能。
